# MyWorkout

![MyWorkout logo](assets/logo.png)

Track what you lift, keep it simple.

## Features
- Create workouts with per-set weights and reps.
- Quick Start list from previously used exercises.
- Build reusable workout templates.
- Log cardio sessions with time and calories.
- View workout history with swipe edit/delete.
- Progress charts for strength, volume, cardio, and consistency.

## Requirements
- iOS 16.0+ (Swift Charts)
- Xcode 15+

## Getting Started
1. Open `MyWorkout.xcodeproj` in Xcode.
2. Select a simulator or device.
3. Run the app.

## Data Storage
Workouts and templates are stored locally in Application Support:
- `MyWorkout/workouts.json`
- `MyWorkout/templates.json`

## Known Limitations
- No cloud sync.
- No user accounts.
- No export yet.
